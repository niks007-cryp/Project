# STRENGTHENED DOMAIN DATA MODEL — LOCAL AI CLIPPER

This document defines the 26 primary domain entities, their fields, relationships, and lifecycle state transitions.

---

## 1. Domain Entity Specifications

### 1. Project
Logical container grouping related long-form media, configurations, and rendered short-form outputs.
- **Fields:** `project_id`, `name`, `description`, `created_at`, `updated_at`, `default_config_id`.

### 2. Source
Metadata representing the origin of ingested media.
- **Fields:** `source_id`, `project_id`, `source_type` (`FILE`, `STREAM`), `source_location`, `owner_creator`, `permission_status` (`AUTHORIZED`, `ORIGINAL_CREATOR`, `UNKNOWN`), `rights_notes`, `created_at`.

### 3. MediaAsset
Physical media file metadata inspected via `ffprobe`.
- **Fields:** `asset_id`, `source_id`, `file_path`, `file_hash_sha256`, `size_bytes`, `duration_seconds`, `container_format`, `video_codec`, `audio_codec`, `width`, `height`, `fps`, `bitrate_kbps`.

### 4. ProcessingJob
Top-level lifecycle controller for a clipping request on a single `MediaAsset`.
- **Fields:** `job_id`, `project_id`, `asset_id`, `status` (`QUEUED`, `RUNNING`, `SUCCEEDED`, `FAILED`, `CANCELLED`), `created_at`, `started_at`, `completed_at`, `current_stage`.

### 5. PipelineRun
Execution instance tracking execution parameters and environment state.
- **Fields:** `run_id`, `job_id`, `pipeline_version`, `config_version_id`, `environment_info` (OS, Python version, GPU model), `started_at`, `completed_at`, `status`.

### 6. PipelineStage
Discrete step within a `PipelineRun` (e.g. `INGESTION`, `TRANSCRIPTION`, `SCENE_ANALYSIS`, `RENDERING`).
- **Fields:** `stage_id`, `run_id`, `stage_name`, `status` (`NOT_STARTED`, `RUNNING`, `SUCCEEDED`, `FAILED`, `SKIPPED`), `start_time`, `end_time`, `duration_ms`, `error_message`, `retry_count`, `checkpoint_hash`.

### 7. Transcript
Root transcript object output by the local ASR engine.
- **Fields:** `transcript_id`, `asset_id`, `asr_model_version_id`, `language`, `duration_seconds`, `created_at`.

### 8. TranscriptSegment
Contiguous speech sentence or phrase snippet within a `Transcript`.
- **Fields:** `segment_id`, `transcript_id`, `speaker_id`, `start_ms`, `end_ms`, `text`, `avg_confidence`.

### 9. TranscriptWord
Word-level alignment token with precise start/end timestamps.
- **Fields:** `word_id`, `segment_id`, `word`, `start_ms`, `end_ms`, `confidence`.

### 10. Speaker
Identified voice persona from diarization.
- **Fields:** `speaker_id`, `transcript_id`, `label` (`SPEAKER_00`, `HOST`, `GUEST`), `voice_signature_hash`.

### 11. Scene
Visual camera cut interval detected via computer vision.
- **Fields:** `scene_id`, `asset_id`, `start_ms`, `end_ms`, `keyframe_path`, `visual_change_score`.

### 12. ClipCandidate
Interval boundary proposed by boundary generation logic before scoring.
- **Fields:** `candidate_id`, `job_id`, `start_ms`, `end_ms`, `duration_seconds`, `boundary_type` (`SEMANTIC`, `SCENE`, `HYBRID`), `hook_text`.

### 13. ClipScore
Evaluation metrics produced by AI scoring models and deterministic rules for a `ClipCandidate`.
- **Fields:** `score_id`, `candidate_id`, `prompt_version_id`, `model_version_id`, `overall_score` (0-100), `hook_score`, `story_arc_score`, `curiosity_score`, `emotional_score`, `standalone_context_score`, `reasoning_text`, `confidence`.

### 14. Clip
A selected high-value clip approved for reframing and rendering.
- **Fields:** `clip_id`, `job_id`, `candidate_id`, `rank`, `title`, `start_ms`, `end_ms`, `status` (`SELECTED`, `HUMAN_EDITED`, `RENDERED`, `QC_PASSED`, `REJECTED`).

### 15. CaptionTrack
Subtitle timeline events generated for a `Clip`.
- **Fields:** `caption_track_id`, `clip_id`, `style_id`, `format` (`ASS`, `SRT`), `file_path`.

### 16. CaptionStyle
Visual template configuration for burned-in captions.
- **Fields:** `style_id`, `font_name`, `font_size`, `primary_color`, `highlight_color`, `outline_color`, `max_words_per_line`, `position_vertical_percent`, `animation_effect`.

### 17. CropTrajectory
Frame-by-frame 9:16 vertical crop window keyframes over time.
- **Fields:** `trajectory_id`, `clip_id`, `source_width`, `source_height`, `target_width`, `target_height`, `keyframes` (list of `{ timestamp_ms, center_x }`), `smoothing_algorithm`.

### 18. RenderJob
Execution task for FFmpeg video filtergraph rendering of a single `Clip`.
- **Fields:** `render_id`, `clip_id`, `output_preset`, `video_codec`, `audio_codec`, `target_fps`, `status`, `duration_ms`.

### 19. RenderedAsset
Output MP4 file generated by a `RenderJob`.
- **Fields:** `rendered_asset_id`, `render_id`, `file_path`, `file_size_bytes`, `file_hash_sha256`, `width`, `height`, `duration_seconds`.

### 20. QCResult
Automated quality control verification report for a `RenderedAsset`.
- **Fields:** `qc_id`, `rendered_asset_id`, `status` (`PASSED`, `FAILED`), `playable_check`, `audio_sync_check` (`drift_ms`), `frozen_frame_check`, `black_frame_check`, `caption_safe_zone_check`, `verified_at`.

### 21. ModelVersion
Registry tracking exact AI/ML model metadata.
- **Fields:** `model_version_id`, `model_name`, `provider`, `version_tag`, `license`, `weights_hash`.

### 22. PromptVersion
Version-controlled prompt template artifact used for LLM scoring.
- **Fields:** `prompt_version_id`, `prompt_name`, `version`, `template_body_hash`, `created_at`.

### 23. ConfigurationVersion
Versioned system settings snapshot applied during a `PipelineRun`.
- **Fields:** `config_version_id`, `config_name`, `version`, `parameters_json_hash`.

### 24. AuditEvent
Immutable record of system operations, state transitions, and user actions.
- **Fields:** `audit_id`, `timestamp`, `job_id`, `event_type`, `actor` (`SYSTEM`, `USER`, `AI`), `details_json`.

### 25. HumanReview
Human-in-the-loop overrides and edits applied to a `Clip` or `ClipCandidate`.
- **Fields:** `review_id`, `clip_id`, `reviewer_id`, `action` (`APPROVE`, `REJECT`, `EDIT_TIMESTAMPS`, `MODIFY_CAPTION`, `MODIFY_CROP`), `original_start_ms`, `modified_start_ms`, `original_end_ms`, `modified_end_ms`, `score_override`, `feedback_notes`, `created_at`.

### 26. PerformanceMetric
System execution metrics logged during job operations.
- **Fields:** `metric_id`, `run_id`, `stage_name`, `cpu_utilization_percent`, `vram_allocated_mb`, `ram_used_mb`, `processing_realtime_ratio`, `timestamp`.

## 3. Lifecycle State Machines

### 3.1 ProcessingJob State Machine
```
[QUEUED] ──► [RUNNING] ──┬──► [SUCCEEDED]
               │         ├──► [FAILED] (Retryable) ──► [RUNNING]
               │         └──► [CANCELLED]
               └────────────► [PERMANENT_FAILURE]
```

### 3.2 Clip Lifecycle State Machine
```
[CANDIDATE] ──► [AI_SCORED] ──► [SELECTED] ──┬──► [HUMAN_EDITED] ──┐
                                             └──► [DIRECT_APPROVED] ┴──► [RENDERING] ──► [QC_PASSED]
```
